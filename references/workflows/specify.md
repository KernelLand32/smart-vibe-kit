# specify

Define **what is true / required** for a topic before or beside implementation.

## Steps

1. Create or open a deliverable from `docs/_templates/deliverable-spec.md`.  
2. Write purpose + sections; prefer citations over invention.  
3. Add a **Verifiable claims** table for every load-bearing fact.  
4. List open questions with stable IDs (`OQ-…`).  
5. Register the doc in `docs/registry.md` for related task IDs.  
6. Do **not** invent UI/API/implementation fiction forbidden by the current stage authorize ADR.  

## Done when

- Spec status reflects reality (`not_started` / `in_progress`)  
- Unknowns are tagged, not faked  
- Gate checklist rows exist (may still be `not_started`)
