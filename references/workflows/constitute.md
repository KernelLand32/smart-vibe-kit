# constitute

Create or refresh the project’s governing rules.

## Steps

1. Read [constitution.md](../constitution.md) (project) or the kit constitution if missing.  
2. Write/update `AGENTS.md` and `docs/constitution.md`.  
3. Customize Articles IV–VI (walls, pins pointer, product constraints).  
4. Ensure `docs/documentation-strategy.md`, `docs/verification-gates.md`, and `docs/toolchain-pins.md` exist.  
5. Confirm agents’ read order lists constitution → registry → tasks → scoped specs → gates.  

## Done when

- `AGENTS.md` and `docs/constitution.md` point at real paths  
- Articles IV–VI are not unedited kit placeholders (or explicitly `[DECISION NEEDED]`)
